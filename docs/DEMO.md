## Recording checklist

Optional human narration segment: record replacement security evidence in Change investigation. Show that open follow-ups block resolution. Close them, refresh the replacement review, check all seven affected items, enter a rationale and resolve the withdrawal. Open the retained approval and revalidation record, then show supported readiness in a fresh session. The supplied automated video includes this working cycle; participant narration remains separate. See [RESTORATION.md](RESTORATION.md).

- Start from a new graph name, seed it, restart the backend and verify the real model before recording.
- Use 1440×900 or a readable viewport; zoom so paths and sources are legible.
- Keep one rehearsal, model warm-up and a backup deterministic walkthrough ready; clearly label deterministic mode if used.
- Keep secrets and unrelated desktop windows off-screen.
- Do not call a deterministic click path a model agent. If inference fails, show the honest error and fix or disclose it.
- Record the actual working workflow; upload and publish only when explicitly authorized.
